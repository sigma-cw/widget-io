# widget.io
**A small extension to simplify widget setup process in StreamElements**

# Requirements
Supported in the following browsers:

- Chrome (Edge, Opera GX, any chromium based browser)
- Firefox (Zen, any firefox based browser)

# Installation
Download from [Chrome Web Store](https://chrome.google.com/webstore/detail/widgetio/fcgbjpajcfjnjgfdeookpnoefgcliljj?hl=en&authuser=3) or [Firefox Add-ons (soon)](#)
